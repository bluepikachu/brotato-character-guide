# Brotato Character Guide Skill

这是一个面向 Agent 的土豆兄弟角色攻略 Skill。

## 它可以做什么

它会回答你某个角色在 `危险5` 难度怎么打，
- 从不同攻略汇总，可提供多个不同的打法
- 直接给出可执行的 Build 建议
- 包含部分道具或机制的解析

## 安装方式

如果你是从 GitHub 安装这份 Skill，可以直接用下面的通用方式。

```bash
npx skills add bluepikachu/brotato-character-guide
```

这个方式支持 `Claude Code`、`Cursor`、`Copilot` 等 `50+ Agent`。

或者你也可以直接告诉你的 Agent：

> 安装这个 Skill GitHub - `bluepikachu/brotato-character-guide`

## 使用方式

使用 `/` 命令调用 Skill，或者直接询问土豆兄弟某个角色攻略即可。

攻略输出的形式如下：

```md

## Steam攻略

- 路线一：`矛` 路线
  - 开局武器：`矛`
  - 前期：先补一点 `幸运` 和 `收获`，再慢慢把资源转成伤害和生存。
  - 中期：继续补输出，同时把均衡角色的经济优势转成稳扎稳打的面板。
  - 后期：属于很平滑、很稳的原始近战路线。
  - 注意事项：Steam 直接把这条标成“更简单”，是它最明确推荐的默认路线之一。

- 路线二：`雷光刀` 路线
  - 开局武器：`雷光刀`
  - 前期：依然要先有一点 `幸运` / `收获` 打底。
  - 中期：这是少见的可以顺手把 `元素伤害` 和近战思路混起来玩的路线。
  - 后期：强度比看起来高，偏有趣而且不弱。
  - 注意事项：这条更像全能者“什么都能玩”的代表分支，不是最无脑，但可玩性高。

- 通用结论
  - Steam 对全能者的总体判断很简单：这角色几乎什么都能玩。
  - 它的优势是开局就有 `收获`，所以很容易把前期过渡做好。
  - 记得把 `幸运` 和 `收获` 的优势尽快转成实战输出，不要一直贪经济不补伤害。

## JUMP攻略

- 开局武器：`冲锋枪`、`双管霰弹枪`
- 前期：主加 `攻击速度`、`伤害`，生存端把 `闪避` 和一点 `护甲` 补起来。
- 中期：`生命窃取` 到 `10左右` 就够用，之后继续补输出。
- 后期：成型后属于很标准的远程爽局，JUMP 的实战记录是一把就过。
- 注意事项：JUMP 这边更偏纯远程、好上手的平滑路线。

## B站攻略

- 开局武器：主推 `双管霰弹枪`
- 前期：全能者没有负面词条，带 `收获` 和 `速度`，前期经济和走位都不错，所以很适合直接玩强势武器。
- 中期：主补 `远程伤害` 和 `攻击速度`，因为 `双管霰弹枪` 对这两个属性很吃。
- 后期：只要前几波顺利把枪凑起来，后面会非常舒服。
- 生存阈值：B站提醒得很明确，`双管霰弹枪` 很贵，前期不要乱买乱锁无关道具，至少保证一两关能补上一把枪，不然很容易进“没枪—没钱—更没枪”的恶性循环。
- 注意事项：B站明确说 `冲锋枪转双管霰弹枪` 虽然老思路很流行，但两种武器要的属性不完全一样，不如纯双管霰弹枪顺手。

## 小黑盒攻略

- 推荐武器：什么都能玩，但更推荐 `冲锋枪`
- 属性优先级：`远程伤害` `>` `伤害` `>` `生命窃取`，其次是 `生命值` `>` `护甲` `>` `攻击速度`
- 整体思路：前期多刷新优先拿武器，升级优先 `远程伤害`，到第七波结束时 `远程伤害` 最好有 `10左右`。
- 注意事项：小黑盒这边明显更偏简单粗暴的远程平推流。

# 其他补充

- B站把全能者放在 `简单` 档，原因很直接：它没有负面机制，前期节奏顺，适合拿来开荒和练基本功。
- 这个角色最重要的不是“找到唯一正确答案”，而是“别把它玩成四不像”。既然它什么都能玩，就更要早点决定一条路线并把属性往那条线上收。
- 如果你只想稳过，当前最省心的三条分别是：`双管霰弹枪`、`冲锋枪`、`矛`。
- 想最省脑子就远程，想要更稳的近战节奏就走 `矛`。

一句话版本：全能者不是“最强”，但它是最不容易犯错的角色之一。稳过就走 `双管霰弹枪` / `冲锋枪` 远程流，想换口味就玩 `矛`，核心是早点定方向，别贪着什么都拿。
```

## 它的限制

- 默认以中文输出，如果你想看英文版本的攻略，推荐直接看 Steam 社区原文这一篇就够了；
- 提供的都是 `危险5` 的攻略，当然拿去打危险 0-4 难度也没问题。但相信我，自己一步步通关危险 0-4，是一个逐渐理解和发现这游戏乐趣的过程；
- 仅有部分道具的攻略，因为这是角色攻略里附带了一些就顺便整理的，并非全面的道具使用攻略，如果想了解属性和道具深层机制，很抱歉它做不到；
- Steam 社区的原文附带很多游戏通关属性图片，如果 Agent 的回复里出现了不理解或者不通顺的地方，建议看看原文；
- 大部分角色内容截止到「张牙舞爪」更新前，「张牙舞爪」的攻略仅 Steam 社区的攻略上有提到一些，所以基本所有攻略也是不包含宠物机制的；

## 补充

- 做成本地检索的优势是检索速度非常快，而且基于真实的玩家攻略，几乎不会出现幻觉；
- 角色强度和使用难度，是基于攻略玩家的体验来讲的，并不绝对，比如有些角色我们玩下来也会和攻略上的体感不一致，这部分的信息仅供参考；
- 这是我们在 OpenClaw 上使用的 Skill，平时打游戏的时候就飞书问两句，感觉很方便。这个 Skill 在过去的一个月里，帮助我们通关了不少角色的 `危险5` 难度，用下来非常舒服，就想着分享出来；
- 2026 年 6 月 17 日上线了新版本「求痛得痛」，Switch 版本还没有更新。这个版本增加了一个「噩梦」难度和一个新角色，我们大概率也不会玩太多，`危险5` 已经给我们带来不少挑战的乐趣了，所以 Skill 里大概率也不会更新了。
